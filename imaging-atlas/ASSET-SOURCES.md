# ImagingAtlas image sources

Source and license pages checked 13 October 2026. These are real publicly shared teaching images, not AI-generated scans. Every comparison uses independent examples, not matched scans of one patient. Files are downloaded unchanged; display scaling in the browser does not alter the files. These image licenses are separate from the website code license. No endorsement by image creators is implied.

CT images here are fixed PNG/JPEG displays without calibrated Hounsfield-unit data. Do not relabel brightness adjustment of these files as true CT windowing.

## Review limits

Source descriptions provide study context. Visual and embedded metadata inspection is used to check for visible names, dates of birth and patient record numbers; this does not establish independent clinical validation. The source for the normal brain CT explicitly states written consent for online publication. Other consent status is not independently established by this atlas.

Visual inspection of all seven downloaded images found no visible patient names, dates of birth or patient record numbers. Embedded EXIF/XMP fields inspected did not reveal these identifiers. Original anatomical labels, measurement marks and orientation letters remain intact.
