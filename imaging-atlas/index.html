Ideal point source · geometry only · not to scale

Distance changes apparent size

Source-to-detector distance stays fixed at 180 cm. As the object moves away from the detector and toward the source, its projected size increases.

Magnification = source–detector distance ÷ source–object distance

Clinical connection: projection and positioning can change the apparent cardiac silhouette. Technique must be considered before concluding that heart size has changed.

SCHEMATIC VESSEL IN B-MODE

Ideal straight vessel · no Doppler data

The plane follows the probe

A plane along a straight vessel's length creates an elongated lumen.

Rotating the probe to a perpendicular plane can show the same vessel in cross-section. Confirm the probe marker and screen convention in the actual examination.

Doppler reminder: red and blue encode the selected flow scale, not oxygenation. Read the scale and direction relative to the probe.
